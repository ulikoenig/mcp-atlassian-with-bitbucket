MCP Atlassian with Bitbucket and Privacy can be installed using several methods. Choose the one that best fits your workflow.

## uvx (Recommended)

The simplest way to run MCP Atlassian with Bitbucket and Privacy without permanent installation using [uvx](https://docs.astral.sh/uv/guides/tools/):

```bash
# Run directly (downloads on first use, cached for subsequent runs)
uvx mcp-atlassian-with-bitbucket-and-privacy --help

# Run with a specific Python version if needed
uvx --python=3.12 mcp-atlassian-with-bitbucket-and-privacy --help
```

  <Tab title="Cursor">
    Open **Settings** → **MCP** → **+ Add new global MCP server**, then use the same JSON configuration.
  </Tab>

  <Tab title="GitHub Copilot (VS Code and CLI)" id="github-copilot">

    See also [the GitHub Copilot documentation](https://docs.github.com/en/copilot/how-tos/copilot-cli/customize-copilot/add-mcp-servers#editing-the-configuration-file).

    MCP server configuration can be stored in either of these files:

    - The global configuration file `~/.copilot/mcp-config.json` (or `$COPILOT_HOME/mcp-config.json`).

    - A Workspace-specific configuration file named `.mcp.json` in the workspace root.
      > IMPORTANT: Don't include secret tokens to this file if is committed in a repository. To avoid including secrets
      > in the `mcp-config.json` file (for example, `JIRA_PERSONAL_TOKEN`), you can reference them with the `${NAME}`
      > syntax. All secrets you wish to reference must be added to the environment variables for your user and will then
      > require a restart of the IDE to take effect.

    Both configuration files expect a top-level `mcpServers` object.

    ```json
    {
      "mcpServers": {
        "mcp-atlassian-with-bitbucket-and-privacy": {
          "type": "stdio",
          "command": "uvx",
          "args": ["mcp-atlassian-with-bitbucket-and-privacy"],
          "env": {
            "JIRA_URL": "https://jira.your-company.com",
            "JIRA_PERSONAL_TOKEN": "${JIRA_PERSONAL_TOKEN}",
            "CONFLUENCE_URL": "https://confluence.your-company.com",
            "CONFLUENCE_PERSONAL_TOKEN": "${CONFLUENCE_PERSONAL_TOKEN}"
          },
          "tools": ["*"]
        }
      }
    }
    ```

## Docker

Docker provides an isolated environment and is recommended for production deployments or when you need specific version control.

```bash
# Pull the latest image
docker pull ghcr.io/ulikoenig/mcp-atlassian-with-bitbucket-and-privacy:latest

# Run with environment variables
docker run --rm -i \
  -e JIRA_URL=https://your-company.atlassian.net \
  -e JIRA_USERNAME=your.email@company.com \
  -e JIRA_API_TOKEN=your_api_token \
  ghcr.io/ulikoenig/mcp-atlassian-with-bitbucket-and-privacy:latest
```

  "mcpServers": {

## pip

Install directly with pip for development or when you need the package in your Python environment:

```bash
pip install mcp-atlassian-with-bitbucket-and-privacy

# Include this extra when PAC/WPAD proxy routing is enabled
pip install "mcp-atlassian-with-bitbucket-and-privacy[wpad]"

# Run the server
mcp-atlassian-with-bitbucket-and-privacy --help
```

## uv

If you're using [uv](https://docs.astral.sh/uv/) for package management:

```bash
# Add to your project
uv add mcp-atlassian-with-bitbucket-and-privacy

# Include this extra when PAC/WPAD proxy routing is enabled
uv add "mcp-atlassian-with-bitbucket-and-privacy[wpad]"

# Run
uv run mcp-atlassian-with-bitbucket-and-privacy --help
```

## From Source

For development or contributing:

```bash
git clone https://github.com/ulikoenig/mcp-atlassian-with-bitbucket.git
cd mcp-atlassian-with-bitbucket
uv sync --frozen --all-extras --dev
uv run mcp-atlassian-with-bitbucket-and-privacy --help
```

See [CONTRIBUTING.md](https://github.com/ulikoenig/mcp-atlassian-with-bitbucket/blob/main/CONTRIBUTING.md) for development setup details.
